# OmniWM 当前配置说明

配置文件：`~/.config/omniwm/settings.toml`。本说明根据 2026-09-21 当前文件整理；之后在设置界面调整，以 TOML 文件为准。

## 本次调整

- 使用 Niri 滚动平铺布局，新窗口默认宽度从 85% 改为 100% 可用宽度。
- 单窗口遵循列宽；宽度预设仍为 33%、50%、67%。
- 总览快捷键改为 Control + ↑，原带 O 的组合键已移除。
- 开启四指上滑打开总览、在总览中四指下滑关闭。
- 关闭三指滑动切换窗口列；工作区滑动、手势移动和缩放窗口也处于关闭状态。
- 临时诊断用 IPC 已关闭。

## 当前外观与行为

- 动画开启，深色外观。
- 窗口间距 16，屏幕四周外边距 0。
- 窗口边框开启，宽度 5，颜色为青色。
- 鼠标悬停跟随焦点开启。
- 总览 Zoom 当前为 50%（不是之前的 100%），背景透明；Option + Shift + 滚动可调整总览缩放。
- 快速终端开启，居中，宽高各占 50%，不自动隐藏，动画时长 0.2 秒。
- 工作区栏开启，高度 24，位置与菜单栏重叠。系统监测按钮已开启，点击可查看 CPU、GPU、内存、磁盘和运行时间。
- 菜单栏图标收纳开启，5 秒后重新收起。
- 防止睡眠开启；剪贴板历史关闭。

## 常用快捷键

| 按键 | 功能 |
| --- | --- |
| Control + ↑ | 打开／关闭总览 |
| Option + ` | 打开／隐藏快速终端 |
| Option + 方向键 | 切换焦点窗口 |
| Option + Shift + 方向键 | 移动窗口 |
| Option + 1…9 | 切换工作区 |
| Option + Shift + 1…9 | 将窗口送到指定工作区 |
| Option + Shift + F | 切换列宽至 100%，再按恢复 |
| Control + Option + F | 扩展列至可用宽度 |
| Option + . / , | 正向／反向循环宽度预设 |
| Option + - / = | 减少／增加列宽 |

## macOS 配套调整（不在此 TOML 中）

- 关闭系统 Control + ↑ 调度中心、Control + ←／→ 切换桌面。
- Control + ↓ 的系统 App Exposé 仍然开启。
- 关闭系统四指上滑调度中心，交由 OmniWM 总览处理。
- 菜单栏设为不自动隐藏。
- AeroSpace 已退出；SketchyBar 和 borders 的 Homebrew 服务已停止。

修改前的配置备份位于 `~/.config/omniwm/backups/`。

## 重启恢复（2026-09-21）

- 开启 OmniWM 的 Start at Login。
- 从 macOS 登录项移除 AeroSpace，避免两个窗口管理器同时启动。
- 关闭“退出应用时关闭窗口”，允许应用恢复窗口。
- 开启 `com.apple.loginwindow TALLogoutSavesState`；关机时保留“再次登录时重新打开窗口”勾选。
- 布局恢复记录在 `~/.local/state/omniwm/runtime-state.json`，实际恢复取决于应用重开窗口及唯一匹配；未执行重启测试。
